# hotvi

Everything for the HOT (Honoring Our Truth) menopause clinic project, run by The Marketing Department (TMD).

Tasks are tracked as issues in this repo and on the **HOTVI Marketing** project in the **The-Marketing-Department** organization. New issues are added to the board in Backlog automatically by `.github/workflows/add-to-project.yml`.

How we use issues, labels and the board is documented in the [TMD Operations Hub README](https://github.com/The-Marketing-Department/tmd#how-we-use-github).
